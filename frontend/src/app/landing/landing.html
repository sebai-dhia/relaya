THE DELIVERY GAP

Why agency handoffs fail with naive AI

Most AI tools hallucinate details, guess missing budgets, or let scope creep bypass engineering approval.

Typical AI & Manual Handoff

The Scope Chaos Problem

  • Silent Hallucinations AI fabricates timelines, features, or budgets when unspecified in client text.
  • Duplicate Board Cards Retried webhook writes spam delivery boards with duplicated tickets and mixed IDs.
  • Unverified Scope Changes Client requests edits post-approval, but developers build against the outdated card.
The Relaya Guarantee

Engineered Rigor & Verification

  • Strict Source Citations & Unknown Flagging Every field maps to exact source excerpts. Absent requirements are highlighted as gaps.
  • SHA-256 Cryptographic Hash Invalidation Approvals bind to exact draft content hashes. Any subsequent edit immediately voids the approval.
  • Idempotent Board Connector Zero board writes without valid approval ID. Strict idempotency key prevents duplicate cards.
UNDER THE HOOD

Production architecture, built clean

Designed with Hexagonal Ports & Adapters, enterprise Spring Boot 4, and reactive Angular 22 Zoneless Signals.

Hexagonal Architecture (Ports & Adapters)

Domain core is pure Java 21 with zero Spring framework dependencies. External AI providers (Groq) and task boards (Trello) plug in strictly at the boundary via ProviderAdapter and BoardConnector.

Domain → Inbound/Outbound Ports → Infrastructure Adapters

Angular 22 Zoneless

Powered by provideZonelessChangeDetection(), fine-grained Signals, and the async resource() API. Zero Zone.js runtime overhead.

Multi-Model Resiliency

Zero-crash dynamic fallback: openai/gpt-oss-120b → openai/gpt-oss-20b → qwen/qwen3.8-27b → synthetic fallback.

Multi-Tenant PostgreSQL

Every entity scoped with tenantId. Flyway automated migrations with immutable UsageLedger token and dollar-cost accounting.

Asynchronous Real-Time SSE Streams

No heavy WebSockets or client-side polling. AI analysis jobs return 202 Accepted, while the frontend subscribes via short-lived tokens to a resilient SSE stream with exponential reconnect backoff.
